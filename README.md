# Apple Stock Sentiment Analysis Tool

## Overview
This Python script combines financial data collection with AI-powered sentiment analysis to provide comprehensive insights into Apple Inc. (AAPL) stock performance and market sentiment.

## What This Tool Does

### 1. 📈 Stock Data Collection
- Downloads historical Apple (AAPL) stock data using the `yfinance` library
- Retrieves data from January 1, 2025 to September 1, 2025
- Includes: Open, High, Low, Close prices, and Volume data

### 2. 📰 News Headline Scraping
- Scrapes current financial news headlines from Yahoo Finance
- Filters results to show only Apple-related news using keywords:
  - `apple`, `aapl`, `iphone`, `ipad`, `mac`, `tim cook`, `cupertino`
- Uses browser headers to avoid blocking

### 3. 🤖 AI-Powered Sentiment Analysis
- Uses **FinBERT** (Financial BERT) - an AI model specifically trained on financial text
- Analyzes each Apple-related headline for sentiment
- Provides three sentiment categories:
  - **Positive**: Bullish/optimistic news
  - **Negative**: Bearish/pessimistic news  
  - **Neutral**: Factual/balanced reporting
- Returns confidence scores (0.0 to 1.0) for each sentiment category

## Files Generated

### `apple_sentiment_analysis.csv`
Contains detailed sentiment analysis results with columns:
- `headline`: The news headline text
- `sentiment`: Primary sentiment classification (positive/negative/neutral)
- `positive`: Confidence score for positive sentiment (0.0-1.0)
- `negative`: Confidence score for negative sentiment (0.0-1.0)
- `neutral`: Confidence score for neutral sentiment (0.0-1.0)

### `stock_data.csv` (optional)
Historical stock price data that can be generated by uncommenting line 19 in `main.py`

## Technical Details

### AI Model: FinBERT
- **Model**: `yiyanghkust/finbert-tone`
- **Purpose**: Financial sentiment analysis
- **Training**: Specifically trained on financial news and reports
- **Output**: Three-class classification (positive/negative/neutral)

### Data Sources
- **Stock Data**: Yahoo Finance via yfinance API
- **News Headlines**: Yahoo Finance web scraping
- **Sentiment Analysis**: Hugging Face Transformers library

### Important Notes
- **Headline-Only Analysis**: Currently analyzes only headlines, not full article content
- **Real-Time Data**: Gets current news headlines from Yahoo Finance
- **Model Download**: First run downloads ~439MB FinBERT model (cached afterward)
- **Rate Limiting**: Includes request headers to avoid being blocked by Yahoo Finance

## Troubleshooting

### Common Issues

2. **No Headlines Found**: Yahoo Finance may have changed their HTML structure
3. **Virtual Environment Issues**: Make sure to activate venv before running
